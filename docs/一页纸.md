# RecLab · 短视频推荐策略实验台

> **一句话**：换一把尺子，冠军就会换人。
> 这个项目交付的不是某个模型，而是一套能守住结论的评测——以及在这套评测下量出来的四件事。

---

## 问题

大多数推荐项目的流程是：随机切分 → 采样负例 → 训一个模型 → 报一个漂亮数字。
这条链路有两个隐患：**训练集含未来信息**、**采样评估系统性高估热门物品**。结果是离线指标好看，换个协议就崩，而且说不清模型赢在哪。

本项目换一条路：先把尺子做准，再谈模型好坏。

## 数据与协议

| | |
|---|---|
| 数据集 | KuaiRec（快手短视频，2020） |
| 规模 | 846,183 条有效观看 · 7,154 用户 · 10,610 视频 |
| 正反馈 | `watch_ratio > 2`（看两遍以上），占全部曝光的 7.5% |
| 切分 | leave-last-out，训练集绝不含测试时刻之后的信息 |
| 评估 | 全量排序（10,610 个候选，不做负采样）+ 稳定 top-k |
| 自检 | 作弊模型 HR@10 = **1.0000**；随机模型 0.0006（理论 0.0009） |

## 结果

| 策略 | HR@10 | NDCG@10 | 长尾 HR@10 |
|---|---|---|---|
| SASRec（自注意力序列） | **0.1416** | **0.0787** | 0.0000 |
| BPR-MF（隐语义） | 0.0505 | 0.0193 | 0.0000 |
| Popular（热度基线） | 0.0141 | 0.0052 | 0.0000 |
| ItemCF（物品共现） | 0.0127 | 0.0052 | 0.0000 |
| 语义召回（内容向量） | 0.0021 | 0.0009 | **0.0070** |

## 四条结论

**① 协议一换，冠军换人。**
随机切分下 ItemCF（0.0635）明显强于 Popular（0.0478）；严格时序下 ItemCF（0.0127）反而输给 Popular（0.0141）。
个性化模型虚高得更厉害（5.0× vs 3.4×），所以宽松协议会系统性夸大「个性化」的价值。

**② 任务一换，冠军再换一次。**
next-item 预测上 SASRec 是 10 倍基线的冠军；换成「覆盖用户 154 个真实兴趣」的稠密召回，
它掉到第三（0.0756），输给 ItemCF（0.1704）。
一个要精度（把概率压尖），一个要广度（把分数摊开）——方向相反。

**③ 长尾是死区，只有内容信号能进。**
按物品流行度分桶后，协同过滤、BPR、SASRec 在长尾桶**全部为 0**，
只有语义召回拿到 0.0070。协同过滤需要共现证据，长尾视频没有；内容信号不需要。

**④ 算法的真实增益，比直觉小得多。**
KuaiRec 对同一批用户做过随机曝光实验，可以配对比较：
有效率从 4.65% 提升到 8.50%，**1.83 倍**（Wilcoxon p < 1e-150）。
更严重的是：**84.5% 的用户，四个模型 top-10 全部落空**，且失败的主力不是极冷物品，
而是 51–200 次交互的「中等热门」。

## 边界与不足

- **单一数据集**：KuaiRec 是 2020 年快手数据，结论外推到其他业务需要重新验证。
- **纯离线**：没有在线 A/B，所有指标只解决模型选型。
- **语义召回是下限**：本机装不上 `sentence-transformers`，用的是 TF-IDF + SVD；换真向量模型应有提升空间。
- **融合不划算**：固定候选预算下，路由版长尾 +21.6% 但整体 −4.08pp（预算守恒）。
